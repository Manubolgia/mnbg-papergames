# Paper Games

Tectonic, Binairo and Sudoku on your phone. There is no stock of puzzles:
each one is made on the device when you ask for it, and each has exactly one
solution that you can reach by reasoning alone, without guessing.

It installs to the home screen and works offline. There's no build step:
`web/` is served as it is. It is also a track in the
[MNBG Tape Library](https://github.com/Manubolgia/mnbglibrary).

---

## The puzzles

| Puzzle | Rules | Settings |
| --- | --- | --- |
| Tectonic | A region of N cells holds 1 to N once each. Cells that touch, even at a corner, never match. | Easy, Hard · 5×5 to 10×10 |
| Binairo | Full or empty squares. Never three alike in a row, each line half and half, no two rows or columns alike. | Easy, Hard · 6×6 to 14×14 |
| Sudoku | 1 to 9 once in every row, column and 3×3 box. | Easy, Medium, Hard |

## How a puzzle is made

1. **A complete grid.** Sudoku fills a grid by randomised backtracking.
   Binairo stacks random legal rows, checking the columns as it goes.
   Tectonic grows random regions of one to five cells, folds most tiny ones
   into their neighbours, and fills them, most constrained cell first; a
   layout that can't be filled quickly is thrown away for a fresh one.
2. **Take clues away.** Cells are cleared one at a time in random order
   (Sudoku in mirrored pairs). After each one a solver that only uses the
   deductions a person would makes an attempt. If it can no longer finish,
   the clue goes back.
3. **Grade it.** Because the solver only ever writes what is forced, getting
   to the end proves the solution is unique. Hard puzzles are only kept if
   the easy techniques alone get stuck.

| Level | Techniques the solver may use |
| --- | --- |
| Sudoku easy / medium | naked and hidden singles (easy keeps at least 38 clues) |
| Sudoku hard | plus pointing and claiming, naked and hidden pairs and triples |
| Binairo easy | pairs and gaps (`xx.`, `x.x`), full counts |
| Binairo hard | plus whole-line reasoning, including "no copy of a finished line" |
| Tectonic easy | naked singles, hidden singles in a region (keeps a fifth of the cells) |
| Tectonic hard | plus "every spot for this number touches that cell", naked pairs and triples |

Every puzzle has a number. The same number, puzzle and settings always make
the same grid.

Puzzles are made in a Web Worker, so the page never stalls. The biggest
(Tectonic 10×10) take up to about a second on a laptop; most take a few
milliseconds.

## Playing

- Tap a cell, then a number. **Notes** switches the pad to pencil marks.
  Placing a number clears it from the notes of every cell that sees it.
- Binairo: tap a cell to cycle full, empty, blank; or use the two keys.
- Cells that break a rule turn red. **Hint** fixes a wrong cell first, else
  fills the selected (or a random) empty cell. **Undo** goes back one move.
- **Sharing a puzzle.** Tap the line under the game's name (`Hard · 8×8 ·
  No. 004211 ↗`) to share it, or copy it when sharing isn't offered. What
  gets sent is the settings, the number and a link such as
  `…/#tectonic/hard-8/4211` or `…/#sudoku/medium/52`, which opens that
  puzzle. Whoever gets it can also choose the same level (and size) on the
  game's page and type the number under **Puzzle number**.
- **English or Spanish.** The two flags on the home screen switch the
  language. It starts in Spanish on a phone set to Spanish, and the choice
  is remembered.
- The game in progress, your settings, solved counts and best times (without
  hints) are kept on the device.
- Keyboard: digits, arrows, Backspace, `N` notes, `H` hint, `U` or Ctrl+Z undo.

## Layout

```
web/                    the app, served as is
  index.html
  styles.css            paper, ink, a ballpoint and a highlighter
  manifest.webmanifest
  sw.js                 offline shell (only ever clears its own caches)
  icons/                generated by tools/make-icons.mjs
  js/
    app.js              views, board, input, storage
    worker.js           makes puzzles off the main thread
    puzzles/
      index.js          one entry point: make(game, settings, number)
      rng.js            seeded randomness
      sudoku.js         generator + graded solver
      binairo.js
      tectonic.js
tools/
  check.mjs             makes a batch at every setting and brute-forces
                        each one to prove it has exactly one solution
  make-icons.mjs        draws the icons
```

## Deploy

1. In the repo's **Settings → Pages**, set **Source** to **GitHub Actions**.
2. Push to `main`. [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)
   runs the checks and publishes `web/` to
   `https://manubolgia.github.io/mnbg-papergames/`.

Open that on the phone and add it to the home screen: on iPhone, **Share →
Add to Home Screen**; on Android, **Install** on the home screen of the app.

## Running locally

```sh
npx http-server web -c-1
node tools/check.mjs        # 6 puzzles per setting; pass a number for more
```
